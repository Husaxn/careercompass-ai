# community

Social, mentoring, networking, and community-driven content.

## Screens

Located in `screens/`. Add one file per screen here:

- `index.tsx` — community feed / discover
- `post.tsx` — a single post or thread detail
- `compose.tsx` — create a new post
- `mentors.tsx` — find and connect with mentors
- `profile.tsx` — public community profile of a member

## What belongs here

- Feed, posts, comments, and reactions
- Mentorship / networking discovery
- Public member profiles and messaging entry points

## What does NOT belong here

- The signed-in user's private profile → `profile`
- AI-generated career recommendations → `recommendations`
