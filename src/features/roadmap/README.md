# roadmap

The generated step-by-step learning / career plan the user follows over time.

## Screens

Located in `screens/`. Add one file per screen here:

- `index.tsx` — the roadmap overview / timeline
- `step.tsx` — detail for a single step, module, or milestone
- `progress.tsx` — progress tracking and milestones

## What belongs here

- Roadmap overview and navigation between phases
- Step/module detail and completion tracking
- Milestones and progress state

## What does NOT belong here

- Where recommendations are generated from → `recommendations`
- Onboarding preview of the roadmap → `onboarding`
- AI analysis of an uploaded source → `analyzer`
